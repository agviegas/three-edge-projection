TSL Learning 05: Parallel Filter Pattern

This is the most important pattern for our edge clipping problem. We need to filter items in parallel: test each item, and if it passes, add it to an output buffer.

The Pattern

Input: [A, B, C, D, E, F, G, H] (8 items to test) GPU threads run in parallel: Thread 0: test A → passes → atomicAdd gets slot 0 → write A to output[0] Thread 1: test B → fails → (skip) Thread 2: test C → passes → atomicAdd gets slot 1 → write C to output[1] Thread 3: test D → passes → atomicAdd gets slot 2 → write D to output[2] Thread 4: test E → fails → (skip) Thread 5: test F → passes → atomicAdd gets slot 3 → write F to output[3] Thread 6: test G → fails → (skip) Thread 7: test H → passes → atomicAdd gets slot 4 → write H to output[4] Output: [A, C, D, F, H] (5 items that passed) Count: 5

Why This Works

The key insight is using atomicAdd to get a unique output slot: 

const outputIndex = atomicAdd(counter, 1);  // Returns current value, then increments
outputBuffer.element(outputIndex).assign(myValue);

Each thread that passes the test gets a unique slot in the output buffer. The order might vary (thread execution order isn't guaranteed), but no data is lost.

Example: Filter Positive Numbers

Given an array of numbers, output only the positive ones.

Click "Run Example" to see the result...

The Code

import * as THREE from 'three/webgpu';
import { Fn, If, instancedArray, instanceIndex, uint, atomicAdd } from 'three/tsl';

// Initialize WebGPU
const renderer = new THREE.WebGPURenderer();
await renderer.init();

// Input data (mix of positive, negative, zero)
const inputData = new Float32Array([-5, 3, 0, 7, -2, 1, -1, 8, 0, 4, -3, 2]);
const inputBuffer = instancedArray(inputData, 'float');

// Output buffer (allocate max possible size)
const outputBuffer = instancedArray(new Float32Array(inputData.length), 'float');

// Atomic counter (initialized to 0)
const counterBuffer = instancedArray(new Uint32Array([0]), 'uint').toAtomic();

// Filter kernel: keep only positive numbers
const filterKernel = Fn(() => {
    const value = inputBuffer.element(instanceIndex);

    If(value.greaterThan(0), () => {
        // Get a unique output slot (atomicAdd returns old value)
        const outputIndex = atomicAdd(counterBuffer.element(0), uint(1));
        outputBuffer.element(outputIndex).assign(value);
    });
})().compute(inputData.length);

// Execute
await renderer.computeAsync(filterKernel);

// Read results
const countBuffer = await renderer.getArrayBufferAsync(counterBuffer.value);
const count = new Uint32Array(countBuffer)[0];

const resultBuffer = await renderer.getArrayBufferAsync(outputBuffer.value);
const results = new Float32Array(resultBuffer).slice(0, count);

console.log(results); // [3, 7, 1, 8, 4, 2] (order may vary)

Connection to Edge Clipping

The edge clipping problem is essentially a parallel filter:

  • Input: Candidate (edge, triangle) pairs
  • Test: Does this edge overlap this triangle when projected?
  • Output: Only the overlaps that exist

Instead of filtering numbers, we filter edge-triangle pairs and output overlap ranges.
