TSL Learning 02: Vectors and Math

In 3D graphics, we work with vectors constantly. TSL provides vec2, vec3, and vec4 types along with all the math operations you'd expect.

TSL vs JavaScript Syntax

TSL looks like JavaScript but compiles to GPU shader code. Here's how operations differ:

JavaScript TSL Notes
a + b a.add(b) Addition
a - b a.sub(b) Subtraction
a * b a.mul(b) Multiplication
a / b a.div(b) Division
a = b a.assign(b) Assignment
let x = ... const x = (...).toVar() Create mutable variable
vec.length() vec.length() Same! (vector magnitude)
vec.normalize() vec.normalize() Same! (unit vector)
a.dot(b) a.dot(b) Same! (dot product)
a.cross(b) a.cross(b) Same! (cross product)

Creating Vectors

// Create a vec3 with literal values
const v1 = vec3(1, 2, 3);

// Access components
v1.x  // → 1
v1.y  // → 2
v1.z  // → 3

// Create from buffer element (common pattern)
const position = buffer.element(instanceIndex).xyz;

// Swizzling (reorder/select components)
v1.xy   // → vec2(1, 2)
v1.zyx  // → vec3(3, 2, 1)
v1.xxx  // → vec3(1, 1, 1)

// Input: 4 points as vec3 (x, y, z, padding) - vec4 for alignment
const points = [
    1, 0, 0, 0,   // Point 0: (1, 0, 0)
    0, 2, 0, 0,   // Point 1: (0, 2, 0)
    3, 4, 0, 0,   // Point 2: (3, 4, 0) - distance should be 5
    1, 1, 1, 0,   // Point 3: (1, 1, 1) - distance should be √3 ≈ 1.73
];

const computeDistances = Fn(() => {
    // Read point as vec3 (ignore the padding)
    const point = pointsBuffer.element(instanceIndex).xyz;

    // Compute distance to origin
    const dist = point.length();

    // Store result
    distancesBuffer.element(instanceIndex).assign(dist);
})().compute(4);
