TSL Learning 06: Geometry Test (Point in Triangle)

Now let's do some actual geometry! We'll test if 2D points are inside a triangle. This is a building block for the edge clipping algorithm.

The Algorithm: Barycentric Coordinates

A point P is inside triangle ABC if it can be expressed as:
P = u*A + v*B + w*C where u + v + w = 1 and all are ≥ 0.

We use the cross product method: check which side of each edge the point is on. If it's on the same side for all three edges, it's inside.

The TSL Code

// Sign of cross product tells us which side of an edge the point is on
const sign = (p, a, b) => {
    return (p.x.sub(b.x)).mul(a.y.sub(b.y))
           .sub((a.x.sub(b.x)).mul(p.y.sub(b.y)));
};

const pointInTriangle = Fn(() => {
    // Load point and triangle
    const point = pointsBuffer.element(instanceIndex).xy;
    const a = triangleBuffer.element(0).xy;
    const b = triangleBuffer.element(1).xy;
    const c = triangleBuffer.element(2).xy;

    // Check which side of each edge the point is on
    const d1 = sign(point, a, b);
    const d2 = sign(point, b, c);
    const d3 = sign(point, c, a);

    // Point is inside if all signs are same (all positive or all negative)
    const hasNeg = d1.lessThan(0).or(d2.lessThan(0)).or(d3.lessThan(0));
    const hasPos = d1.greaterThan(0).or(d2.greaterThan(0)).or(d3.greaterThan(0));

    const inside = hasNeg.and(hasPos).not();  // NOT(has both signs)
    resultsBuffer.element(instanceIndex).assign(inside);
})().compute(numPoints);
