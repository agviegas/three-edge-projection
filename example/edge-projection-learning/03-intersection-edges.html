03: Intersection Edges - Where Objects Meet

When two 3D objects overlap, they create new visible edges where their surfaces intersect. These aren't edges of the original mesh - they're new lines that appear where geometry penetrates other geometry.

Why We Need Intersection Edges

With Intersection Edges

The Challenge

Finding intersections between two meshes naively requires checking every triangle against every other triangle - that's O(n²) complexity. For meshes with thousands of triangles, this would be impossibly slow.

The solution: BVH (Bounding Volume Hierarchy) acceleration. Using bvhcast() from the three-mesh-bvh library, we can skip large portions of both meshes that can't possibly intersect.

The Algorithm

1

BVH Cast

We use bvhA.bvhcast(bvhB, matrix) to efficiently find all pairs of triangles that might intersect. This traverses both BVH trees simultaneously. 

bvhA.bvhcast(bvhB, matrixBToA, {
    intersectsTriangles: (tri1, tri2) => {
        // Called only for potentially intersecting pairs!
        // The BVH already filtered out most triangles
    }
});
2

Skip Shared Edges

If two triangles share 2 or more vertices, they're adjacent (share an edge). We skip these - they're handled by the normal edge extraction. 

function areTrianglesOnEdge(t1, t2) {
    const indices = ['a', 'b', 'c'];
    let sharedVertices = 0;

    for (let i = 0; i < 3; i++) {
        for (let j = 0; j < 3; j++) {
            if (t1[indices[i]].distanceTo(t2[indices[j]]) < 1e-10) {
                sharedVertices++;
            }
        }
    }

    return sharedVertices >= 2;  // 2+ shared vertices = shared edge
}
3

Skip Parallel Triangles

If two triangles are nearly parallel (normals point in same/opposite direction), they either don't intersect or intersect along an entire edge (coplanar). We skip these cases. 

// Check if triangles are parallel
if (Math.abs(tri1.plane.normal.dot(tri2.plane.normal)) > 1 - 1e-6) {
    return false;  // Skip - nearly parallel
}
4

Calculate Intersection Line

Use Three.js's built-in intersectsTriangle() to find the actual intersection line between two triangles. 

const line = new Line3();

if (tri1.intersectsTriangle(tri2, line, true)) {
    // line.start and line.end now contain the intersection
    // The 'true' parameter means "compute the line"
}
5

Filter Edge-Aligned Intersections

If the intersection line lies exactly along an edge of either triangle, skip it. These are handled by normal edge detection. 

if (
    tri1.intersectsTriangle(tri2, line, true) &&
    !isLineTriangleEdge(tri1, line) &&  // Not on tri1's edge
    !isLineTriangleEdge(tri2, line)    // Not on tri2's edge
) {
    target.push(line.clone());
}

Handling Multiple Meshes

The EdgeGenerator checks intersections between all pairs of meshes in a scene: 

// For N meshes, check all pairs
for (let i = 0; i < meshes.length; i++) {
    for (let j = i; j < meshes.length; j++) {  // j = i to include self-intersection
        const meshA = meshes[i];
        const meshB = meshes[j];

        // Transform B's coordinates into A's local space
        _BtoA.copy(meshA.matrixWorld).invert().multiply(meshB.matrixWorld);

        // Find intersections
        generateIntersectionEdges(bvhA, bvhB, _BtoA, results);

        // Transform results back to world space
        transformEdges(results, meshA.matrixWorld);
    }
}

Self-Intersection

Notice that j = i (not j = i + 1). This means we also check each mesh against itself. This catches cases where a single mesh has triangles that penetrate other parts of itself (non-manifold or overlapping geometry).

The Complete Flow

┌─────────────────────────────────────────────────────────────────┐ │ generateIntersectionEdges() │ ├─────────────────────────────────────────────────────────────────┤ │ │ │ INPUT: Two BVHs (bvhA, bvhB) + transformation matrix │ │ │ │ bvhA.bvhcast(bvhB, matrix): │ │ │ │ │ └─► for each potentially-intersecting triangle pair: │ │ │ │ │ ├─► Skip if triangles share an edge (2+ vertices) │ │ │ │ │ ├─► Update triangle planes if needed │ │ │ │ │ ├─► Skip if triangles are nearly parallel │ │ │ │ │ ├─► Calculate intersection line │ │ │ │ │ ├─► Skip if line lies on triangle edge │ │ │ │ │ └─► ADD intersection Line3 to output │ │ │ │ OUTPUT: Array of Line3 (intersection edges) │ │ │ └─────────────────────────────────────────────────────────────────┘

Performance Consideration

Intersection edge detection can be expensive for complex scenes with many overlapping objects. If your scene doesn't have intersecting geometry, you can disable this feature: 

generator.includeIntersectionEdges = false;
