TSL Learning 01: Hello Compute

This is the simplest possible WebGPU compute shader using Three.js TSL (Three Shading Language). We'll create a compute shader that doubles each number in an array.

The Concept

A compute shader runs on the GPU in parallel. Instead of processing pixels for rendering, it processes arbitrary data. Think of it like a massively parallel for-loop. 

// CPU (sequential):
for (let i = 0; i < 1000; i++) {
    data[i] = data[i] * 2;
}

// GPU (parallel):
// All 1000 elements are processed SIMULTANEOUSLY
// Each "thread" knows its index via `instanceIndex`

Key TSL Concepts

  • instancedArray() - Creates a GPU buffer from a typed array
  • instanceIndex - Built-in variable: which thread am I? (0, 1, 2, ...)
  • Fn() - Defines a TSL function (like a shader)
  • .compute(N) - Request N total invocations (threads)

Understanding .compute(N) and Workgroups

GPUs execute work in groups called workgroups. By default, each workgroup has 64 threads. The .compute(N) argument specifies the total number of invocations you need. Three.js divides this by the workgroup size to determine how many workgroups to dispatch. 

// .compute(5) with default workgroup size of 64:
// → dispatches 1 workgroup (ceil(5/64) = 1)
// → 64 threads run, but only 5 are "useful"

// .compute(100) with default workgroup size of 64:
// → dispatches 2 workgroups (ceil(100/64) = 2)
// → 128 threads run, but only 100 are "useful"

Important: Extra threads beyond your data size will still run and may access out-of-bounds memory! For production code, always guard with bounds checking.

The Code

// 1. Create input data
const inputData = new Float32Array([1, 2, 3, 4, 5]);

// 2. Upload to GPU buffer
const buffer = instancedArray(inputData, 'float');

// 3. Define compute shader
const computeShader = Fn(() => {
    // Each thread reads its element, doubles it, writes it back
    const value = buffer.element(instanceIndex);
    value.assign(value.mul(2));
})().compute(5);  // Request 5 invocations (1 workgroup of 64 threads runs)

// 4. Execute on GPU
await renderer.computeAsync(computeShader);

// 5. Read results back to CPU
const result = await renderer.getArrayBufferAsync(buffer.value);

What's Happening?

  1. We create a Float32Array with 5 numbers: [1, 2, 3, 4, 5]
  2. Upload it to the GPU as a storage buffer
  3. Define a compute shader that multiplies each element by 2
  4. The GPU runs 5 parallel threads, each processing one element
  5. We read the results back: [2, 4, 6, 8, 10]
