TSL Learning 03: Conditionals (If/Else)

GPU shaders need conditionals too! TSL provides If, ElseIf, and Else that look different from JavaScript but work similarly.

Syntax Comparison

JavaScript TSL 
if (x > 5) {
    result = 1;
}
 
If(x.greaterThan(5), () => {
    result.assign(1);
});
 
if (x > 5) {
    result = 1;
} else {
    result = 0;
}
 
If(x.greaterThan(5), () => {
    result.assign(1);
}).Else(() => {
    result.assign(0);
});
 
if (x > 5) {
    result = 2;
} else if (x > 0) {
    result = 1;
} else {
    result = 0;
}
 
If(x.greaterThan(5), () => {
    result.assign(2);
}).ElseIf(x.greaterThan(0), () => {
    result.assign(1);
}).Else(() => {
    result.assign(0);
});

Comparison Operators

JavaScript TSL
a > ba.greaterThan(b)
a >= ba.greaterThanEqual(b)
a < ba.lessThan(b)
a <= ba.lessThanEqual(b)
a === ba.equal(b)
a !== ba.notEqual(b)
a && ba.and(b)
a || ba.or(b)
!aa.not()

Example: Classify Numbers

Let's classify numbers as negative (-1), zero (0), or positive (1).

Click "Run Example" to see the result...

The Code

const classify = Fn(() => {
    const value = inputBuffer.element(instanceIndex);
    const result = float(0).toVar();  // Create mutable variable

    If(value.lessThan(0), () => {
        result.assign(-1);
    }).ElseIf(value.greaterThan(0), () => {
        result.assign(1);
    });
    // If value === 0, result stays 0

    outputBuffer.element(instanceIndex).assign(result);
})().compute(N);

Important: toVar()

In TSL, values are immutable by default. To create a variable you can modify, use .toVar(): 

// This creates an immutable value (can't assign to it later)
const x = float(5);

// This creates a mutable variable (can use .assign())
const y = float(5).toVar();
y.assign(10);  // OK!
